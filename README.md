Developed a Streamlit-based churn prediction app featuring a dashboard and a prediction page that
accepted user inputs to determine churn likelihood. Employed GridSearchCV to choose best    
parameters and algorithms among multiple classification algorithms, ultimately achieving ~90% 
accuracy using XGBoost.
